# 🤖 SmartRoutine - Android Automation Hub

A lightweight, open-source automation app for Android to streamline daily tasks, battery saving, and device settings with a single tap.

---

## ✨ Features (المميزات)
* **Smart Power Saving:** Automatically adjusts screen brightness and volume when connected to a charger.
* **Connection Management:** Quick toggles and automation rules for Wi-Fi and Bluetooth.
* **Privacy Focused:** Runs completely locally on your device with zero data collection.
* **Lightweight & Fast:** Built natively with Kotlin for maximum performance and minimum battery consumption.

---

## 🚀 Getting Started (كيفية البدء)
1. Clone the repository or download the APK.
2. Open the project in **Android Studio**.
3. Build and run the app on your Android device.
